# Cách ra lệnh cho agent chạy quảng cáo

Gửi người dùng phần này khi họ ra lệnh thiếu ý ("chạy ads đi"). Mục tiêu: agent chọn đúng nhánh, dựng đúng cấu trúc, không phải hỏi lại, không bịa.

## Một lệnh đủ ý = 7 mục + 3 câu an toàn

`[MỤC TIÊU] cho [SẢN PHẨM/OFFER, GIÁ] — Page [PAGE] — tài khoản [TÀI KHOẢN] — ngân sách [SỐ]đ/ngày — chạy [THỜI GIAN] — tệp [GIỚI/TUỔI/ĐỊA BÀN/SỞ THÍCH] — dùng [BÀI/VIDEO/ẢNH] — [CẤU TRÚC nếu scale].`

1. Mục tiêu: bán hàng web · lead web · lead form · tin nhắn · tương tác bài · livestream.
2. Sản phẩm / offer / giá.
3. Page (và tài khoản quảng cáo nếu có nhiều).
4. Ngân sách VND/ngày (hoặc ngân sách test + tổng).
5. Thời gian: bắt đầu, số ngày.
6. Tệp: giới, tuổi, địa bàn, sở thích / lookalike.
7. Creative: link bài / video / ảnh.

**3 câu an toàn:** "để PAUSED chờ tôi duyệt" · "dùng token BM" hoặc "dùng Zernio" · "theo SOP scale" (khi scale).

## Mẫu

- **Bán hàng web:** "Chạy camp bán hàng cho [sản phẩm, giá] trên Page [X], [Y]đ/ngày, VN [tuổi], video [link], tối ưu Purchase. Để PAUSED chờ duyệt."
- **Tương tác bài:** "Chạy camp tương tác bài viết cho Page [X], boost bài [link], [Y]đ/ngày, VN 25–44, bỏ WhatsApp và Threads, không nút CTA, để PAUSED."
- **Lead form:** "Camp lead form [sản phẩm], Page [X], [Y]đ/ngày, VN [tuổi], form hỏi tên + SĐT + [câu lọc], để PAUSED."
- **Tin nhắn:** "Camp tin nhắn Messenger cho [sản phẩm], Page [X], [Y]đ/ngày, chạy 8h–22h, lời chào '[...]', để PAUSED."
- **Test (giai đoạn 1):** "Test CBO 1-3-5 cho [sản phẩm], 1,5tr/ngày, 3 ad set Broad / LAL 1% / Sở thích, mỗi ad set 5 video [links], 3 ngày, để PAUSED."
- **Scale dọc:** "Tạo ABO 1-1-1 cho video thắng [link], Broad, bắt đầu [Y]đ/ngày, 1 bật 2 tắt, để PAUSED."
- **Scale ngang:** "Nhân bản ABO 1-1-1 gốc [ID] thành Scale 2 (LAL 1%) và Scale 3 (Broad + loại trừ xem video và tương tác Page 7 ngày), mỗi bản [Y]đ, dùng bài viết có sẵn, để PAUSED."
- **Đổi ngân sách:** "Tăng ngân sách ad set [ID] 20% (từ [a] lên [b]đ/ngày)."
- **Báo cáo:** "Báo cáo camp [ID] 7 ngày qua, cấp ad, tính theo đăng ký."

## Từ khoá agent hiểu ngay

| Câu | Nghĩa |
|---|---|
| `để PAUSED chờ duyệt` | Tạo xong không bật |
| `bật luôn` | Người dùng cho phép bật đúng đối tượng này |
| `dùng token BM` / `dùng Zernio` | Chọn đường thực thi |
| `theo SOP scale` | Áp dụng `test-scale.md` |
| `boost bài <link>` | Lấy post ID từ link, dùng bài có sẵn |
| `1-1-1`, `ABO`, `CBO 1-3-5` | Chọn cấu trúc |
| `tăng X%` / `giảm 30%` | Chỉ đổi ngân sách khi được yêu cầu |

## Câu nên tránh

- "Chạy quảng cáo đi" / "target cho ngon" / "chạy sao cũng được": thiếu ý, agent phải hỏi lại.
- "Tự chọn ngân sách giúp mình": agent không được tự quyết chi tiêu; sẽ đưa phương án để chọn.
- Gộp test + scale + đổi ngân sách trong một lệnh: khó kiểm soát.

## Ví dụ xấu → tốt

- Xấu: "Chạy ads tương tác cho page."
- Tốt: "Chạy camp tương tác bài viết cho Page [tên Page], boost bài [link], 50k/ngày, VN 25–44, bỏ WhatsApp và Threads, không CTA, để PAUSED chờ duyệt. Dùng token BM."
